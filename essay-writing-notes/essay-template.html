2如何选项目（万能模板第一步）
✓
推荐选择
  • 中大型商业项目：金额 400W 以上，研发周期 8 个月以上
  • 政府/大型信息系统：国企、事业单位、军方、医院、银行、股份公司的 ERP/OA、云计算/大数据系统
✗
不建议选
  • 小型企业项目：进销存、图书管理、单机版
  • 尚未完成的项目（须已完成并上线，最好三年内）
  • 纯建网站：静态门户无后台大型应用
  • 硬件项目：综合布线、安防、视频会议
  • 纯技术项目：数据迁移、内部技术研究

零基础怎么办？参考范文用别人项目模仿，或去 GitHub 找开源项目读文档，让大模型按考试需求生成文章再熟悉。

3摘要（300~330字 · 提前准备）

万能公式

  • 公式：时间 + 项目 + 项目简介 + 个人岗位 + 工作职责 + 投入 + 历时 + 成功交付客户好评 + 结合具体题目说明本文结构
  • 逻辑分两段：第一段通用介绍项目背景；第二段按论文题目发挥、回应子题目并介绍结构
  • 包含：项目名称、（金额、历时）、团队介绍、项目简介、我的责任、本文讨论主题概括

关键注意事项

  • 摘要与正文是总分关系，不是承接关系——摘要写过的东西正文还要写，但正文不能续着摘要写
  • 注意字数：第一段写多了，第二段收着写
4项目背景（350-450字 · 提前准备）
  • 公式：为什么做这个项目 + 岗位职责 + 项目规模 + 开发周期 + 项目功能和技术介绍 + 回应子题目并过渡到主体
  • 不要写太多、会显得啰嗦；尽量通用化、不要和论文主题相关，考试时无论什么主题都可直接默写
  • 在背景最后写一句过渡语句，过渡到下一个论点
  • 内容：项目开发的原因、你的岗位职责、开发周期及规模、功能介绍、所用技术
5正文与结尾

正文（1200字左右）

  • 按论文题目和子题目要求写作，一定要回应论文子题目
  • 正文不在万能模板里，需按不同题目准备——先准备好万能模板，正文后补

结尾（400-600字 · 整体补救的最后一步）

  • 公式：项目上线及运行效果 + 客户评价 + 项目收获 + 项目不足和解决思路
  • 弹性策略：字数不够 → 结尾多写；字数多了 → 结尾少写；前面写得很差 → 结尾一定要重视
  • 不足要写小问题（别出现大问题），写"经过后期纠偏没对项目产生影响"
6六大常见问题（官方答疑）
问题回答 1. 字数怎么分配？摘要300 + 背景400 + 回应子题200 + 主体1000 + 结尾300；总 2000~2600 2. 没做过架构师怎么办？专业人员从架构师角度写熟悉项目；零基础参考范文+大模型拆解生成文章再记忆 3. 内部项目没客户？当普通项目写：某年某月公司要做什么项目，任命我为架构师，结尾仍写"客户一致满意" 4. 要不要写论文题目？不需要 5. 项目背景怎么构造？时间离考试3-5年内、持续8个月+、已完成；级别省市级/集团级；名称写"某地级市/某医院/某公司"；金额与人数/时间对应（20人×15月≈600万） 6. 不会写论文？第一篇耗时很正常，目的是学会"题目+知识点+模板+项目"结合；第一篇完成备考就完成一半；AI时代要学会用大模型助力
◆ 费曼

万能模板=把论文拆成 5 个"预制件"，考前背熟、考场拼装。 摘要和背景是最值钱的两个预制件——背景（350-450字）刻意写成"与任何题目无关"，这样考场上直接默写，只需末尾加一句过渡。摘要按"时间+项目+岗位+职责+投入+历时+好评+结构"八件套填空。正文是唯一不能预制、必须针对题目写 1200 字的部分（回应子题+技术决策+量化效果）。结尾是"字数调节阀"，多了删、少了补。口诀：背景要"万金油"，摘要要"八件套"，正文必须"贴题"，结尾负责"找平"。

▸ 总结

万能模板=选项目（400W+/8个月+，避开小项目/未完成/纯网站/硬件/纯技术）→ 摘要300字（时间+项目+岗位+职责+投入+历时+好评+结构八件套）→ 背景400字（刻意通用化的万金油，考场默写+过渡句）→ 正文1200字（必须回应子题目）→ 结尾300字（上线效果+客户评价+收获+不足，兼当字数调节阀）；总字数2000~2600；项目背景虚构要合理（时间3-5年内、级别省市级、金额与团队人数匹配）。
