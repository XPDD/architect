▸ 核心要点
1多核处理器的概念与优势

多核指多个微处理器内核，将两个或更多微处理器封装在一起、集成在一个电路中。多核处理器是单枚芯片，能直接插入单一处理器插槽。

  • 多核与多 CPU 相比，降低了功耗和体积。
  • 由操作系统软件进行调度，多进程、多线程并发都可以。
2三种运行模式
模式全称含义
AMP非对称多处理2 个内核彼此不同，各自处理特定功能，在软件协调下分担不同计算任务
SMP对称多处理2 颗完全一样的处理器封装在一芯片内，达到双倍/接近双倍处理性能，节省运算资源
BMP混合多处理与 SMP 类似，但可指定某任务仅在某个指定内核上执行

每种模式适合解决特定问题、对 OS 要求各不相同，采用哪种模式需考虑硬件的差异情况。

3多核 CPU 的调度算法
全局队列调度
  • OS 维护一个全局任务等待队列
  • 有 CPU 空闲时从全局队列选取就绪任务执行
  • CPU 核心利用率高
→
局部队列调度
  • OS 为每个 CPU 内核维护局部队列
  • 该内核空闲时从自己的队列选任务
  • 优点：无需在多个 CPU 间切换，利于提高 Cache 命中率
4记忆口诀

A 非对称（各司其职）、S 对称（相同双胞胎）、B 混合（可指定内核）；全局=一个队列、局部=每核一队列。

◆ 费曼

多核 = 把好几个「大脑」塞进一颗芯片：省功耗、省体积，靠操作系统来调度。三个模式像三种团队分工——AMP 是「各管一摊」的不同专家，SMP 是「一模一样的双胞胎」干同样的活，BMP 是「双胞胎但可以点名让某人专干某事」。调度上，全局队列像一个公共任务池（利用率高），局部队列像每人一个专属任务池（不用跨核切换、缓存命中率高）。

▸ 总结

多核=单芯片多内核，降功耗体积；三模式=AMP（非对称各司其职）、SMP（对称同核）、BMP（混合可指定）；调度=全局队列（一个队列、利用率高）/局部队列（每核一队列、免切换）。
