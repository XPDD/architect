▸ 核心要点
1按字长与集成度分类

按字长：4 / 8 / 16 / 32 / 64 位。16 位及以下称嵌入式微控制器，32 位及以上称嵌入式微处理器。

按系统集成度：一般用途型微处理器（内部仅含单纯 CPU 单元）vs 单芯片微控制器（Single Chip Microcontroller，把 CPU、ROM、RAM、I/O 集成到同一芯片）。

2按用途四类（核心考点）
1
MCU 微控制器（单片机）
  • CPU + 片内内存 + 片内外设
  • CPU/RAM/ROM/定时器/I/O 集成一片
  • 体积小、功耗成本低、适控制
  • 嵌入式系统工业主流
2
MPU 微处理器
  • 由通用 CPU 演变，仅 CPU
  • 32 位以上，性能高、价格高
  • 需外挂 DDR / FLASH
  • 代表：ARM、MIPS、POWER PC
3
DSP 数字信号处理器
  • 专用于信号处理，特殊设计
  • 哈佛结构 + 流水线
  • 比最快 CPU 还快 10–50 倍
  • 强项：大量运算（滤波/FFT/图像/通信）
4
SoC 片上系统
  • 控制部件 + 执行部件集成一片
  • 软硬件无缝结合，嵌入 OS 代码
  • 片内可再编程
  • 手机/平板/安防/TWS 耳机等
3四类处理器对比速查
类型集成内容特点应用
MCUCPU+内存+外设单片化、低成本低功耗、适控制遥控器、家电、无人机
MPU仅 CPU32 位以上、高性能、外挂存储器高性能计算、复杂算法
DSP信号处理专用哈佛+流水线、速度极快、大量运算滤波/FFT/通信/图像/医学
SoC整系统+软件软硬无缝结合、可再编程手机/平板/IoT/穿戴
4为何嵌入式系统多用微控制器
  • 节约成本和节省功耗：多芯片集成在一片内，制造使用成本、功耗更低。
  • 简化硬件设计：微控制器集成大量外设，硬件设计大幅简化。
5记忆口诀

MCU 控制、MPU 计算、DSP 运算、SoC 集成；「大量运算」永远选 DSP，不是 MPU。

◆ 费曼

四种处理器 = 四种「职能分工」：MCU 是把整台电脑缩成一颗芯片的「全能管家」，便宜省电专门做控制；MPU 是只保留大脑（CPU）的「精英」，算力强但要外挂内存；DSP 是「算数狂魔」，专门用哈佛结构+流水线高速跑大量运算；SoC 是把硬件加软件全打包的「成品套餐」，手机耳机里都是它。

▸ 总结

字长：≤16 位=微控制器、≥32 位=微处理器；按用途四类=MCU（控制/单片机）、MPU（计算/ARM）、DSP（大量运算/哈佛流水线）、SoC（软硬集成/可再编程）。「大量运算」选 DSP。
