# 康奈尔笔记总结

将分析报告的结论提炼为一页纸康奈尔笔记，提供四种 HTML 模板风格，包含费曼白话解释和图示逻辑关系。

## 模板文件

四种风格可选，所有模板共用相同的 `{{VARIABLE}}` 占位符和 HTML 结构，仅 CSS 不同。

| 模板 | 风格 | 适用场景 |
|------|------|---------|
| `template-tech.html` | 科技风 | 暗色主题、霓虹光效、等宽字体，适合数据/技术类报告 |
| `template-business.html` | 商务风 | 藏蓝+金色、精致典雅，适合咨询/投资/高管汇报 |
| `template-github.html` | GitHub 风 | 明亮简洁、绿蓝点缀、开源感，适合产品/开发类报告 |
| `template-apple.html` | 苹果风 | 极简留白、SF 字体、大圆角，适合设计/品牌类报告 |

所有模板均支持响应式布局，在 ≤768px 屏幕（手机/平板竖屏）下自动切换为单列堆叠布局。

**默认使用科技风模板**，用户可通过触发词切换："用商务风格"、"用 GitHub 风格"、"用苹果风格"。

## 康奈尔笔记布局

```
┌──────── 线索栏（左 25%）───┬─────── 笔记栏（右 60%）──────┐
│  关键问题                  │  核心要点                    │
│  ? 问题1                  │  · 要点1                    │
│  ? 问题2                  │  · 要点2                    │
│  ? 问题3                  │  · 要点3                    │
│                           │                              │
│                           │  🧒 费曼笔记（说人话）       │
│                           │  📊 图示法（逻辑关系图）     │
├───────────────────────────┴─────────────────────────────┤
│                    总结栏（底 15%）                      │
│  一句话概括 + 标签                                       │
└─────────────────────────────────────────────────────────┘
```

## 核心原则

1. **一页纸** — 所有内容必须容纳在一页 A4 纸内
2. **高信息密度** — 用编号分区、对比块、卡片网格、数据栏承载更多结论，而非仅平铺要点列表
3. **费曼精神** — 必须用大白话解释核心结论，不用行业术语
4. **可视化** — 结论间有因果/对比/分层关系时，必须用图示呈现
5. **问题驱动** — 线索栏的每个问题，右侧笔记栏都能找到答案

## 触发与确认

当用户在对话中表达总结意图（如"总结一下报告"、"帮我梳理要点"、"概括一下"、"提取结论"等），skill 应先推荐本模板，简要说明输出形式：

> 我可以帮你把这份报告用**康奈尔笔记**的形式提炼成一页纸，包含：关键问题、核心要点、大白话解释（费曼笔记）、逻辑关系图，并提供四种视觉风格可选（科技风/商务风/GitHub风/苹果风）。要为这份报告生成吗？

待用户明确同意（如"好"、"可以"、"生成"）后，再执行生成流程。

## 生成流程

1. 读取报告文件，按信息要素识别规则抽取对比关系、并列主题、关键数字、章节结构、关键词（详见 [references/extraction-guide.md](references/extraction-guide.md)）
2. 按模板填充规范将要素映射为组件（详见 [references/cornell-layout.md](references/cornell-layout.md)）
3. 根据用户指定的风格，读取对应的模板文件（默认 `template-tech.html`），替换所有 `{{VARIABLE}}` 占位符
4. 将填充后的 HTML 写入 `reports/{{标题}}_康奈尔笔记.html`

## 高密度组件

| 组件 | 用途 | 详细文档 |
|------|------|---------|
| `numbered-header` | 编号分区，组织笔记栏结构 | [extraction-guide.md](references/extraction-guide.md) |
| `vs-block` | 左右对比（旧 vs 新、A vs B） | [extraction-guide.md](references/extraction-guide.md) |
| `card-grid` | ABCD 并列卡片网格（2-4 张） | [extraction-guide.md](references/extraction-guide.md) |
| `stat-row` | 关键数字统计栏（3-5 个） | [extraction-guide.md](references/extraction-guide.md) |
| `hl-orange/green/purple` | 多色关键词高亮 | [extraction-guide.md](references/extraction-guide.md) |

## 图示选择

| 关系类型 | 使用组件 | 示例场景 |
|---------|---------|---------|
| 因果/时序 | `flow-box` + `flow-arrow` | 因素A→结果B→影响C |
| 多维对比 | `compare-table` | 竞品对比、方案优劣 |
| 分层/包含 | `flow-box` + `flow-v-arrow` | 市场→细分→品牌 |

详见 [references/cornell-layout.md](references/cornell-layout.md) 中的图示示例。
