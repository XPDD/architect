分论点二：K8s 编排、状态外置与零信任安全

RUNTIME
名词 · TERM是什么 · WHAT为什么 · WHY解决什么问题 · PROBLEM SOLVED
KubernetesK8s 容器编排平台 · Orchestration容器编排平台（调度/部署/伸缩/自愈）容器多了要统一管人工调度、故障恢复、资源分配
Deployment无状态部署对象 · Stateless管无状态应用的声明式对象声明期望状态，K8s 自动收敛滚动更新、Pod 挂了自动重建
探针（就绪/存活）量化:秒级Probe · Readiness / Liveness健康检查：存活=进程活着(死则重启)；就绪=能接流量(否则摘除)进程活着 ≠ 可服务发布秒级摘除异常实例、平滑滚动
HPA 自动伸缩Horizontal Pod Autoscaler按指标（CPU 70%）自动增减副本流量有峰谷，人工调不现实弹性：高峰扩容、低谷回收（1-5 副本）
StatefulSet核心有状态副本集 · Stateful管有状态应用，实例有稳定身份+持久存储Agent 有状态（在线/记忆/会话/沙箱），Deployment 管不了有状态实例的稳定标识、状态保存与恢复
状态机 + 心跳State Machine + Heartbeat状态机定义生命周期（部署中/在线/离线/工作中）；心跳定期上报"活着"要统一登记监控每个实例真实状态Agent 状态不可视、假死检测、统一监控
存储计算分离Storage-Compute Separation计算与数据分离：状态/记忆→PostgreSQL，文件/产出→OSS实例是临时的、数据是持久的状态外置：实例重建后状态可恢复
NetworkPolicy量化:端口网络策略 · Zero Trust集群内网络白名单（按端口/IP/标签）默认集群内全通，要最小访问缩小攻击面：入口仅 3001，出口仅 53/5432/443
零信任Zero Trust默认不信任任何网络位置，逐请求认证授权内网不可信服务间最小权限、边界安全升级
WebShell/WebSocket 代理Bidirectional Proxy用 client-node 把浏览器操作代理到远端实例/沙箱Agent 在远端/沙箱，需要安全运维通道免暴露 SSH 即可安全运维远端实例
