▸ 核心要点
1定义与提出者

层次分析法（AHP，Analytic Hierarchy Process）由美国运筹学家 Thomas L. Saaty 于 20 世纪 70 年代提出，是一种把定性问题与定量分析结合起来的多准则决策方法。

  • 核心：把人的主观判断通过"两两比较"转化为数量权重，从而对方案排序。
  • 常用于方案选型、指标权重确定、可行性分析等场景。
2三个层次结构
◆ AHP 层次结构（自上而下）
目标层（最高层）
要解决的决策目标
↓
准则层（中间层）
评价准则，可再分子准则
↓
方案层（最低层）
备选方案，最终排序
3构造判断矩阵 + 1–9 标度

对同一层元素两两比较，用 1–9 标度表示相对重要程度，构成判断矩阵 A（aij = 1 / aji，对角线为 1）。

标度含义（i 相对 j）
1两个元素同等重要
3i 比 j 稍重要
5i 比 j 明显重要
7i 比 j 强烈重要
9i 比 j 极端重要
2,4,6,8上述相邻判断的中间值
倒数j 比 i 的重要性 = 1/aij
4计算权重（方根法 / 特征向量法）
  • 方根法：每行元素连乘 → 开 n 次方 → 归一化，得到权重向量 W，即各元素相对权重。
  • 特征向量法：求判断矩阵的最大特征值 λmax 对应的特征向量，归一化得权重。
W_i = (∏_j a_ij)^(1/n) # 行连乘开 n 次方 w_i = W_i / Σ_i W_i # 归一化即权重
5一致性检验（关键步骤）

人做两两比较可能前后矛盾，需检验判断矩阵是否一致：

CI = (λ_max − n) / (n − 1) # 一致性指标 CR = CI / RI # 一致性比率 # CR < 0.1 → 一致性可接受；否则需重新调整判断矩阵

随机一致性指标 RI（查表）：n=1→0，2→0，3→0.58，4→0.90，5→1.12，6→1.24，7→1.32，8→1.41，9→1.45。

  • 判读口诀：CR < 0.1 通过；否则矩阵自相矛盾，要回去改判断。
6易错辨析（考点）
  • AHP 是 Saaty 提出的通用多准则决策方法（定性 + 定量）。
  • SAAM / ATAM / CBAM 是软件架构评估方法，不是 Saaty 提出的通用决策模型——选择题常拿它们做干扰项。
  • CBAM 也强调"成本—收益—效用"，但它是架构评估方法，别与 AHP 混。
◆ 费曼

AHP 说人话：遇到"选哪个方案好"这种说不清的问题，AHP 让你别一次给总分，而是两两比一比——"A 比 B 重要多少？"用 1–9 打个分，把所有两两比较填成一张判断矩阵；再算出每个因素的权重，最后排序。它把"拍脑袋的感觉"换成了"一串能算的数字"，所以叫定性问题定量化。算完还要做一致性检验：确认你的打分没自相矛盾（CR < 0.1 才算过关）。

▸ 总结

AHP（层次分析法）＝ Thomas L. Saaty 提出、把定性问题与定量分析结合的多准则决策方法。步骤：建层次（目标→准则→方案）→ 两两比较构造判断矩阵(1–9 标度) → 方根法/特征向量求权重 → 一致性检验 (CI=(λmax−n)/(n−1)，CR=CI/RI，CR<0.1 通过) → 综合排序。辨析：SAAM/ATAM/CBAM 是架构评估方法，勿与 AHP 混淆。
