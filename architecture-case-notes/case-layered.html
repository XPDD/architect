案例分析题 — 电子小票服务系统
试题 · 案例分析（25 分）
物联网三层架构
3 个小问 · 可展开参考答案
试题一
阅读以下关于电子小票服务系统的说明，回答问题 1 至问题 3。
P1 · 层次架构
【说明】

某科技公司面向连锁商超开发一套「电子小票服务系统」。用户消费后不再打印纸质小票，而是由小票智能硬件采集收银机待打印的购物小票数据，经 Wi-Fi / GPRS 无线网络上传至云端，用户可通过终端应用随时查看历史小票、查询积分、兑换商品。系统整体基于物联网三层架构构建，自下而上组成如下：

  • 应用层：云平台小票服务（实时推送、历史查询、积分）+ 云平台数据服务（经营数据分析、精准推荐、畅销品排名）。
  • 网络层：电子小票云平台基础服务——数据传输处理、数据存储、硬件设备管理、商家管理、会员管理、商品管理。
  • 感知层：小票智能硬件——系统设计、驱动程序、控制程序，负责采集收银机待打印购物小票。
◆ 系统分层架构（自下而上）

云平台小票服务（实时推送/历史查询/积分）＋ 云平台数据服务（经营数据/精准推荐/畅销品排名）
↕ 互联网

感知层

问题 1指出该系统采用的架构风格，并说明物联网三层架构各层的主要作用。8 分

该系统采用了物联网三层架构（感知层 / 网络层 / 应用层）。请结合上图，分别说明感知层、网络层、应用层的主要作用与相互之间的数据传递关系。

参考答案
  • 感知层：识别物体、采集信息——负责把「人类世界与物理世界的数据」采集进来，类似人体的皮肤和五官；本系统中即小票智能硬件（系统设计/驱动/控制程序）采集收银机待打印购物小票。
  • 网络层：传递和处理信息——负责把感知层采集的数据安全传至云端并做初步处理，类似神经中枢和大脑；本系统即电子小票云平台基础服务（数据传输处理、存储、设备/商家/会员/商品管理）。
  • 应用层：实现广泛智能化——解决信息处理与人机交互问题，类似社会分工；本系统即云平台小票服务与云平台数据服务。
  • 数据流向：感知层采集 → 网络层传输/预处理 → 应用层加工展示，逐层向上解耦；反向控制指令沿应用层→网络层→感知层下发。
问题 2小票智能硬件属于哪一层？该层通常需要通过哪些编程技术实现其控制程序，为什么？8 分

结合图中「系统设计、驱动程序、控制程序」的提法，指出小票智能硬件所处层次，并说明其控制程序一般基于什么开发；物联网感知层设备大量使用嵌入式技术，其开发语言、驱动、系统设计有何要求。

参考答案
  • 属于感知层。小票智能硬件是联网终端，负责采集收银机待打印小票数据并上传。
  • 控制程序一般基于嵌入式技术开发（如 C 语言、RTOS / 裸机开发），因为感知层设备资源受限、需近实时响应、功耗与成本敏感。
  • 驱动程序：负责驱动底层硬件（打印口、通信模块、传感器等）完成数据读取；系统设计：规划数据采集、缓存与上行策略（断网本地缓存、联网补传）。
问题 3若云平台数据服务要基于用户历史小票生成「精准推荐」，该功能应位于哪一层？说明理由。9 分

精准推荐需要汇聚大量消费者历史行为数据进行挖掘分析。请判断该能力所属层次，并结合该层「数据 + 应用」的职责说明为什么放在该层，以及它对系统处理数据能力（智能计算 / 云计算）的要求。

参考答案
  • 应位于应用层（云平台数据服务）。精准推荐属于「实现广泛智能化」的信息处理与人机交互范畴，必须基于海量消费数据进行汇总、分析、挖掘。
  • 该层职责是「数据 + 应用」：借助云计算 / 智能计算支撑大数据分析、挖掘与推荐算法，故放在应用层。
  • 这一层依赖网络层汇聚上传的用户行为数据（历史小票、消费频次、商品类别等），是典型的「数据驱动应用」。畅销品排名、经营数据分析同理，均归属应用层的数据服务。
