案例分析题 — 混合云安全生产管理系统
试题 · 案例分析（25 分）
混合云 + 4 层架构
3 个小问 · 可展开参考答案
试题四
阅读以下关于大型企业混合云安全生产管理系统的说明，回答问题 1 至问题 3。
P4 · 安全架构
【说明】

跨区域的安全生产管理是大型集团企业面临的主要问题。大型企业希望通过云计算实现异地的设计、生产、制造、管理和数据处理，同时确保企业内部生产的安全、保密与数据完整。由于私有云面向企业用户、数据存放更安全，而企业又希望获得公有云的弹性计算资源，因此采用混合云（融合公有云 + 私有云）成为首选。

  • 智能工厂内部采用私有云，实现产品设计、数据共享与生产集成。
  • 公司总部与智能工厂之间采用公有云，实现智能工厂间、工厂与总部间的业务管理、协调与统计分析。
◆ 安全生产管理系统 4 层架构（自上而下）
应用层
云计算平台信息处理：数据 + 应用
↑
设计 / 管理层
智能工厂开发、业务控制、数据管理，实现数据集成与应用
↑
控制层
智能工厂自动控制系统，控制智能设备完成生产
↑
设备层
智能工厂生产产品所需的相关设备
问题 1说明该系统为何采用混合云，并指出私有云与公有云分别承担什么角色。8 分

大型企业出于安全考虑更愿意把数据放在私有云，同时又希望获得公有云的计算资源。请结合混合云定义说明其价值，并分别说明私有云与公有云在该系统中的作用。

参考答案
  • 混合云价值：融合公有云与私有云的优点，既满足敏感数据的安全 / 保密诉求，又能享受公有云的弹性计算资源，做到「既省钱又安全」。
  • 私有云：面向企业用户，数据存放在私有云更安全；用于智能工厂内部——产品设计、数据共享、生产集成。
  • 公有云：提供弹性计算资源；用于公司总部与智能工厂之间——智能工厂间、工厂与总部间的业务管理、协调与统计分析。
问题 2该系统分为哪几层？分别说明各层职责。8 分

如图所示，安全生产管理系统由四层组成。请按自上而下的顺序写出各层名称，并说明每层承担的功能。

参考答案
  • 应用层：在云计算平台上进行信息处理，两大核心功能——「数据」与「应用」。
  • 设计 / 管理层：智能工厂各种开发、业务控制和数据管理功能的集合，实现数据集成与应用。
  • 控制层：智能工厂建立的一套自动控制系统，控制智能设备完成生产工作。
  • 设备层：智能工厂生产产品所需的相关设备。
问题 3为保证企业安全、保密与数据完整，安全体系应从哪些方面设计？9 分

该系统涉及异地设计 / 生产 / 数据共享。请从安全体系的构建角度，说明应从哪些方面进行安全设计（物理 / 系统 / 网络 / 应用 / 安全管理），并简述如何保证数据库完整性。

参考答案
  • 物理安全：机房 / 设备 / 场地环境防护。系统安全：操作系统补丁、加固、防病毒。网络安全：边界防护、加密传输、访问控制。应用安全：身份认证、授权、最小权限。安全管理：安全制度、规程、应急响应与安全审计。
  • 可结合三道防线（产品安全架构 + 安全技术体系架构 + 审计架构）与 WPDRRC（预警 / 保护 / 检测 / 响应 / 恢复 / 反击，配人员 / 策略 / 技术）落实持续安全。
  • 数据库完整性＝数据的正确性与相容性，由完整性约束保证；静态约束尽量在数据库模式实现，动态约束由应用程序实现，实体完整性 / 引用完整性优先，慎用触发器，并在需求阶段确立约束命名规范。
