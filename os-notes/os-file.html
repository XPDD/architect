▸ 核心要点
1索引文件结构（重点计算）

典型 13 个索引节点：0~9 直接索引（存内容）、10 一级间接（存盘块地址）、11 二级间接（存一级地址）、12 三级间接。每块 4KB、地址 4B → 一块可存 4KB/4B = 1024 个地址。

索引可存数据
直接（10 个）10 × 4KB = 40KB
一级间接（1 个）1024 × 4KB = 4MB
二级间接（1 个）1024 × 1024 × 4KB = 4GB
2树形目录与路径
  • 相对路径：从当前目录开始的路径；
  • 绝对路径：从根目录开始的路径；
  • 全文件名 = 绝对路径 + 文件名。

注意：绝对路径、相对路径都不含最后的文件名，只是路径序列。

3文件属性

R 只读 · A 存档 · S 系统 · H 隐藏（口诀：RA SH）。文件名组成 = 驱动器号 + 路径 + 主文件名 + 扩展名。

4空间存储管理
方法原理
空闲区表法空闲空间整合成表（空闲文件目录）
空闲链表法空闲空间链接成链表，按需分配
成组链接法分组 + 组内链表，前两者综合
位示图法每位标识一个物理块，1=使用、0=空闲
5位示图计算（重点）

字长 32 位，块号 4195：字号 = 4195 / 32 = 131 → 第 132 个字；位号 = 4195 % 32 = 3 → 第 4 位（从 0 起），分配后置 1。

◆ 费曼

索引文件 = 文件的「三级快递站」：直接索引是「货架」（直接放内容，小件 40KB），一级间接是「中转站」（放 1024 个货架地址，4MB），二级间接是「总调度」（1024×1024 个地址，4GB），每加一级容量翻 1024 倍。位示图是「停车场车位图」，一个 bit 一个车位，1 已停 0 空着——找块号就是算第几个字、第几位。

▸ 总结

索引=直接 40KB / 一级 4MB / 二级 4GB（每级 ×1024）；路径=相对(当前起)/绝对(根起)/全文件名(绝对+文件名)；属性=R/A/S/H；位示图=1 用 0 空，字号=块号/字长、位号=块号%字长。
