▸ 核心要点
1页式存储

程序远大于内存，故分固定大小页（一般 4K），离散入内存块，用页表映射。每个页 = 页号 + 页内地址。

物理地址 = 块号 × 块大小 + 页内偏移（块号由页表查到）。

  • 优点：利用率高、碎片小（仅最后页有）、分配管理简单。
  • 缺点：增加系统开销，可能产生抖动。
2快表 vs 慢表
慢表
  • 页表存于内存中
  • 需访问两次内存才能取数据
  • 速度慢
vs
快表（相联存储器）
  • 页表存于 Cache 中
  • 按内容访问、硬件并行查找，速度快
  • 存放最频繁页号的副本，访问一次 Cache + 一次内存
3段式存储

按逻辑整体分段，每段大小不同。地址 = （段号，段内偏移），物理地址 = 段基地址 + 段内偏移。段内偏移不能超过段长，否则越界错误。

  • 优点：程序逻辑完整、修改互不影响。
  • 缺点：内存碎片浪费大、利用率低。
4段页式存储

先分段、后分页。

  • 优点：空间浪费小、存储共享容易、能动态连接。
  • 缺点：管理软件增加、复杂性和开销增加、执行速度下降。
5页面置换算法

缺页=需执行的页不在内存、需从外存调入，缺页越多效率越低。

算法原理特点
OPT 最优淘汰未来最长时间不被访问的页理论算法，无法实现，作对比基准
FIFO 先进先出淘汰最先调入的页会产生抖动（Belady 异常）
LRU 最近最少使用淘汰最近过去最久未使用的页基于局部性原理，效率高、不抖动
◆ 费曼

内存不够、页表来凑：程序切成固定 4K 的「豆腐块」，页表当「门牌号对照表」，逻辑地址（页号+偏移）一查表就变物理地址（块号+偏移）。快表是 Cache 里的「常用门牌小抄」，查一次就够；慢表得翻两次内存。段式是「按功能撕面包」、大小不一，段页式先撕再切。换页三兄弟：OPT 是「事后诸葛亮」（最优但做不到），FIFO 是「先来先走」（会抖动），LRU 是「最久没用的走」（最靠谱）。

逻辑地址
→
页表查块号
→
物理地址 = 块号×块大小 + 页内偏移
段式：物理地址 = 段基地址 + 段内偏移（偏移不超段长）

▸ 总结

页式=固定大小页+页表映射（块号×块大小+偏移）；段式=逻辑分段（基地址+偏移，越界检查）；段页式=先段后页；快表=Cache 相联存储器一次访存；置换=OPT 理论最优 / FIFO 会抖动 / LRU 局部性不抖动。
