01

分布式系统

原题 19CQRS
考点：CQRS 把命令（写）模型与查询（读）模型彻底拆开，各自独立建模与存储。
易错：最大代价是两模型间数据同步与最终一致性处理更复杂，不是更简单；读写分离引入的是最终一致而非强一致。
原题 64微服务调用容错
考点：对方偶尔延迟 → 最直接的是设置超时时间，超时快速失败并释放线程。
易错：熔断（持续失败才用）、限流（控速率）、降级（兜底）都过重。
02

企业信息化 · 法律法规

原题 37专利制度
考点：申请权与专利权均可依法转让。
易错：科学发现不授专利权；侵权诉讼时效自知道 / 应当知道被侵害之日起算（非授权公告日）；实用新型保护产品形状构造，不保护文学艺术作品。
原题 60信息网络传播权
考点：信息网络传播权 = 以有线 / 无线方式向公众提供作品，使其可在个人选定的时间和地点获得。
易错：发表权 = 是否公之于众；发行权 = 提供原件 / 复制件；署名权 = 表明作者身份。
03

操作系统

原题 50中断处理
考点：中断响应、取中断向量、转入入口地址由 CPU 硬件完成；保存 / 恢复现场、调度控制才是 OS 中断处理程序的职责。
易错：把"中断响应与转入入口"当成 OS 的工作 → 错。
原题 65文件分配方式
考点：索引分配用索引表记录数据块地址，既支持变长文件又支持随机访问。
易错：连续分配随机访问好但不适变长；链接分配支持变长但只能顺序访问。
04

数据库

原题 32自然连接元组数
考点：自然连接按公共属性等值匹配；若某侧连接属性是主键（值唯一），则为"一对多"。
易错：R.B 是主键 → 每个 S 元组最多配 1 个 R → 上界 = |S| = 10；下界可为 0 → [0,10]（不是 [5,10]）。
原题 39E-R 联系基数
考点：基数看问的是哪一侧。"学生必须且只能属于一个班级"→ 学生侧 (1,1)。
易错：(10,50) 是班级侧对学生人数的约束，别答错侧。

软件工程

原题 21装饰器模式
考点：Decorator 属结构型模式，运行期动态给对象叠加职责，比继承灵活。
易错：它基于抽象构件 Component 接口层层包装——"只能用于具体类"是错的；符合开闭原则。
原题 24DO-178 vs CMMI
考点：DO-178 是航空适航专用标准，要求更具体、目标更清晰；CMMI 是通用过程能力成熟度模型。
易错：适用范围更广的是 CMMI；航空合规细节是 DO-178 强项。
06

系统分析与设计

原题 42AHP
考点：AHP 层次分析法由 Thomas L. Saaty 提出，用判断矩阵把定性判断转定量计算。
易错：SAAM / ATAM / CBAM 是软件架构评估方法，不是 Saaty 的通用决策模型。
原题 53结构化分析工具
考点：DFD 描述功能 / 数据流动、数据字典描述数据、状态转换图 STD 描述行为模型。
易错：E-R 图是数据建模、甘特图是进度工具，都不是行为模型。
07

软件测试方法

原题 36因果图法
考点：黑盒中因果图法专分析多输入条件的组合及因果约束（与 / 或 / 非 / 互斥），再转判定表设计用例。
易错：边界值管边界、等价类管分区、错误推测靠经验，都不擅长条件组合。
08

系统可靠性分析

原题 23DO-178B 软件等级
考点：按失效后果由重到轻 A→E：A 灾难性 / B 危险严重 / C 重大（显著降低应对不利运行条件能力） / D 较小 / E 无影响。
易错："显著降低"对应 C 级，不是 A/B。
09

软件架构质量属性

原题 58软件架构评估
考点：架构评估（SAAM / ATAM）需各类干系人参与，围绕质量属性场景做权衡分析。
易错："敏感点一定只影响一个构件的特性"是错的——敏感点可影响一个或多个构件，别与"对单一质量属性敏感"混淆。

扩展 · 人工智能

原题 46规则系统
考点：专家系统（知识库 + 推理机 + IF-THEN 产生式规则）是典型规则系统。
易错：编译系统 = 语言翻译、操作系统 = 资源管理、DB 缓冲池 = 性能机制，都不是规则推理核心。
