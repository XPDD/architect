开发模型
1（2025下）敏捷开发模式下，有三个角色、固定迭代周期、且每天有站会的方法是( )
A. 看板B. 极限编程C. 精益（Lean）D. Scrum
答案：D
Scrum 核心要素：三个角色（PO、Scrum Master、开发团队）、固定 Sprint 周期（1-4周）、每日站会。看板无固定迭代周期；极限编程侧重工程实践；精益强调消除浪费。
2（2026上）关于 V 模型的表述，正确的是( )
A. 测试活动只在编码完成后才开始B. 测试阶段与开发阶段形成对应验证关系C. 它完全以风险分析为驱动D. 它强调原型快速迭代优先于文档
答案：B
V 模型：左侧开发→右侧对应测试，形成一一验证关系。A 错在"只"；C 是螺旋模型；D 是原型模型。
3（2026上）在敏捷开发中，测试活动通常从( )就开始介入。
A. 需求阶段B. 概要设计阶段C. 详细设计阶段D. 上线验收阶段
答案：A
测试左移：敏捷强调测试从需求阶段即介入（需求评审、编写验收标准），尽早发现缺陷降低修复成本。
4（2025上）以下哪个开发模型会增加风险评估的环节？
A. 瀑布模型B. 螺旋模型C. V 模型D. 增量模型
答案：B
螺旋模型 由 Boehm 提出，以风险分析为驱动。每次迭代：目标制定→风险评估→开发验证→规划下一轮。
4+1 视图 & RUP
5（2025上 16-17）4+1 视图中，描述软件到硬件的映射是(16)视图；关注运行状态的是(17)视图。
16: A.逻辑视图 B.进程视图 C.物理视图 D.用例视图
17: A.逻辑视图 B.进程视图 C.实现视图 D.部署视图
答案：(16) C · 物理视图  |  (17) B · 进程视图
逻辑→功能；进程→并发/运行状态；物理→部署拓扑；实现→模块组织；用例(+1)→场景驱动。
6（2025上）RUP 中，确定体系结构及工作计划与资源配置是哪个阶段？
A. 初始B. 细化C. 构造D. 移交
答案：B
RUP 四阶段：初始→确定范围可行性；细化→体系结构、计划、资源；构造→编码实现；移交→部署培训。
7（2025上）Scrum Backlog 是以( )为标准进行需求排序的。
A. 实现难易度B. 商业价值C. 最后期限D. 技术成熟度
答案：B
Product Backlog 由 PO 维护，按商业价值优先级排序，高价值条目先进入 Sprint。
结构化分析
8（2025下）以下属于结构化分析特点的是( )
A. 自底向上B. 面向数据流C. 非直接耦合D. 数据耦合
答案：B
结构化分析（SA）核心：自顶向下、面向数据流，用 DFD 描述功能。A 是结构化设计(SD)特点；C/D 是耦合概念。
9（2025下）数据流图中哪个组件表示数据加工和转换？
A. 外部实体B. 处理C. 数据流D. 数据存储
答案：B
DFD 四要素：外部实体(来源/去向)、处理/加工(数据变换)、数据流(传递路径)、数据存储(暂存/持久化)。
10（2025下）判定树和判定表主要用来分析数据流图中的( )
A. 数据流B. 加工C. 数据存储D. 外部项
答案：B
判定树/判定表用于描述加工逻辑(Process Specification)，即数据如何被变换。
11（2026上）在结构化分析方法中，用于描述系统行为模型的工具是( )
A. 数据流图B. E-R 图C. 状态转换图D. 甘特图
答案：C
三种模型：DFD→功能模型；E-R→数据模型；状态转换图→行为模型。甘特图是项目管理工具。
需求管理
12（2025上）关于需求管理正确的说法是( )
A. 为达到过程能力成熟度模型第二级，组织机构必须具有 3 个关键过程域
B. 需求的稳定性不属于需求属性
C. 需求变更的管理过程遵循变更分析和成本计算、问题分析和变更描述、变更实现的顺序
D. 变更控制委员会对项目中任何基线工作产品的变更都可以做出决定
答案：D
CCB 有权审批基线变更。A: CMMI L2 有 7 个 PA；B: 稳定性是需求属性；C: 正确顺序为"问题分析→变更分析→变更实现"。
13（2025上 58）下列关于需求追踪描述错误的是( )
A. 正向跟踪：需求→设计→代码→测试 的覆盖
B. 反向跟踪：工作成果→需求说明书的来源
C. 正向+逆向合称"双向跟踪"
D. 需求跟踪主要作用在实施阶段，变更阶段作用有限
答案：D
需求跟踪在变更阶段作用巨大——通过追踪矩阵快速评估变更影响范围。A/B/C 均正确。
内聚
14（2025上 68）内聚类型从高到低的正确排序是( )
A. 顺序、通信、过程、逻辑、功能、时间
B. 功能、顺序、通信、过程、时间、逻辑
C. 逻辑、顺序、过程、功能、时间、通信
D. 时间、功能、过程、通信、顺序、逻辑
答案：B
高→低：功能 > 顺序 > 通信 > 过程 > 时间 > 逻辑。口诀：功顺通过时逻偶。
15（2025下 44）模块接收工作量清单，计算"前三工人名单"和"日均工作量"，内聚类型是( )
A. 逻辑内聚B. 顺序内聚C. 通信内聚D. 功能内聚
答案：D
功能内聚：所有元素共同完成单一明确功能("工作量统计")。顺序内聚需有先后依赖；通信内聚仅数据关联；逻辑内聚是同类逻辑类别。

16（2025上 7）符合 A/B 测试的是( )
A. 同一时间，分别让分组成分相同的访问群组随机访问这些版本
B. 不同时间，分别让分组成分互补的访问群组随机访问这些版本
C. 同一时间，分别让分组成分互补的访问群组随机访问这些版本
D. 不同时间，分别让分组成分相同的访问群组随机访问这些版本
答案：A
A/B 测试：同一时间，成分相同的群组随机访问不同版本，对比效果差异。排除时间变量干扰，确保群体同质性。
17（2025上 14）不属于 Web 服务器性能评测方法的是( )
A. 基准性能测试B. 压力测试C. 可靠性测试D. UI 测试
答案：D
A/B/C 均属性能评测；UI 测试属于功能/体验测试，衡量的是界面交互而非性能指标。
18（2025上 36）不属于黑盒测试的方法是( )
A. 等价类划分法B. 因果图C. 路径覆盖D. 边界值分析
答案：C
路径覆盖是白盒测试方法（需了解内部逻辑）。A/B/D 均为黑盒测试（不关心内部结构）。
19（2025上 54）条件覆盖与判定覆盖的关系是( )
A. 条件覆盖强于判定覆盖B. 判定覆盖强于条件覆盖C. 条件覆盖不一定包含判定覆盖，判定覆盖也不一定包含条件覆盖D. 两者等价
答案：C
两者无包含关系。例如 if(A||B): 判定覆盖只需 A=T 或 B=T；条件覆盖需同时测 A=T/F 和 B=T/F，但仍不能保证判定为真。条件/判定覆盖(CDC)才同时满足两者。
20（2025上 55）软件测试中哪个说法是错误的？
A. 测试永远在调试后B. 测试用于检查需求C. 调试起始于不明确的条件D. 测试可以预估周期
答案：A
测试和调试无固定先后——测试发现缺陷后进行调试定位修复，过程中可能再次测试验证。
21（2025上 56）单元测试的依据是( )
A. 需求分析文档B. 概要设计C. 详细设计D. 用户需求
答案：C
单元测试依据详细设计文档（含模块接口、算法、数据结构）。集成测试依据概要设计；确认/验收测试依据需求文档。
22（2025上 62）软件回归测试的目的是( )
A. 不引入新 bugB. 提高测试覆盖率C. 验证需求实现D. 发现系统缺陷
答案：A
回归测试目的：确保修改（修 bug、增功能）后不引入新的缺陷，已有功能仍然正常。

A. 单元测试、集成测试、确认测试B. 集成测试、有效性测试、单元测试C. 单元测试、有效性测试、集成测试D. 有效性测试、单元测试、集成测试
答案：A

26（2025下 61）Web 服务器评测中，压力测试之前应( )
A. 测试系统高负载下的资源占用B. 不断提高压力直到系统崩溃C. 验证系统在正常情况下的资源占比D. 测试系统的并发用户承载上限
答案：C
压力测试前先做基准测试——验证正常负载下的性能基线，再逐步加压。A/B/D 都是压力测试过程中的操作。
27（2025下 69）软件测试的核心目的是( )
A. 证明软件的正确性B. 证明软件无缺陷C. 验证软件是否符合所有需求D. 发现程序错误，降低风险
答案：D
测试不能证明软件正确/无缺陷，其核心目的是发现错误、降低质量风险。Dijkstra: "测试能证明缺陷存在，但不能证明不存在。"

逆向工程与软件复用
32（2025下 22）在逆向工程中，使用用户指导下的搜索与变换方法通常可导出哪两个层级？
A. 实现级和结构级B. 领域级和功能级C. 功能级和结构级D. 实现级和功能级
答案：C
逆向工程抽象层次（低→高）：实现级→结构级→功能级→领域级。用户指导下的搜索与变换可导出功能级和结构级。
33（2026上 56）在软件复用方式中，开发之前就有计划地进行复用规划，属于( )
A. 机会复用B. 系统复用C. 临时复用D. 被动复用
答案：B
系统复用（Systematic Reuse）：开发前有计划地进行复用规划，建立可复用资产库，自上而下推动。机会复用则是开发中遇到合适组件顺便复用，无预先计划。
UML 建模
34（2025上 25）用例模型不包含哪种关系？
A. 包含B. 扩展C. 泛化D. 聚合
答案：D
用例之间的关系：包含(Include)、扩展(Extend)、泛化(Generalization)。聚合(Aggregation)属于类之间的关系，不属于用例模型。
35（2025上 52）下列有关活动图的说法，错误的是( )
A. 活动是原子的，不可以被中断B. 泳道用于分配活动给不同对象或角色C. 完成活动需要消耗一定时间D. 分叉(Fork)是判断，分支(Decision)是多线程并发
答案：D
D 描述完全反了：分叉(Fork)→多线程并发，分支(Decision)→条件判断择路。B/C 正确；A 中 Action（动作）才是原子的不可中断，Activity（活动）可被中断。
36（2025上 53）UML 哪种图用于物理结构建模？
A. 部署图B. 用例图C. 类图D. 活动图
答案：A
部署图（Deployment Diagram）描述系统的物理部署拓扑（节点、硬件、网络）。用例图→功能需求；类图→逻辑结构；活动图→流程行为。
37（2026上 44）A 用例在 B 用例执行的特定扩展点插入附加行为，且 B 可独立存在，A 与 B 的关系是( )
A. 包含B. 扩展C. 泛化D. 依赖
答案：B
扩展(Extend)：在特定扩展点可选插入附加行为，基用例可独立存在。
对比：包含(Include)→必须调用，不可省略；泛化→子用例继承父用例行为。
设计模式
38（2025下 36）以下属于创建型设计模式的是( )
A. 抽象工厂模式B. 观察者模式C. 桥接模式D. 装饰器模式
答案：A
创建型：工厂方法、抽象工厂、建造者、原型、单例。
B 观察者→行为型；C 桥接→结构型；D 装饰器→结构型。
39（2026上 21）关于装饰器模式的说法，错误的是( )
A. 属于结构型模式B. 可在运行期间动态添加职责C. 只能用于具体类，不能基于抽象构件工作D. 比静态继承更灵活
答案：C
装饰器模式恰恰基于抽象构件(Component)工作——定义抽象构件接口，具体构件和装饰器均实现该接口。C 说法错误。
40（2026上）单例模式（Singleton Pattern）属于( )设计模式。
A. 创建型B. 结构型C. 行为型D. 并发型
答案：A
单例模式确保类只有一个实例，属于创建型设计模式。GoF 23 种模式分为：创建型5种、结构型7种、行为型11种。
