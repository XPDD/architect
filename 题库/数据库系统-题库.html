关系代数
2025 年
1 关系代数运算不包括( )
A. 选择 B. 投影 C. 删除 D. 连接
答案：C
关系代数基本运算：选择(σ)、投影(π)、并(∪)、差(−)、笛卡尔积(×)、重命名(ρ)。连接(⋈)是派生运算。"删除"属于 DML 操作，不在关系代数范畴。
2 数据库 R−(R−S) 与( )等价。
A. R∩S B. R∪S C. R−S D. R×S
答案：A
集合恒等式：R − (R − S) = R ∩ S
推导：R − (R − S) = { x | x∈R ∧ x∉(R−S) } = { x | x∈R ∧ ¬(x∈R ∧ x∉S) } = { x | x∈R ∧ (x∉R ∨ x∈S) } = { x | x∈R ∧ x∈S } = R ∩ S。
3 在 SQL 中，SELECT 执行结果是( )
A. 元组 B. 集合 C. 属性值 D. 序偶
答案：B
SQL 查询结果是一个结果集（集合），即满足条件的元组的集合。在关系模型中，关系被定义为元组的集合（set），SELECT 返回的正是这样一个关系/集合。

4 关系 R(A,B) 有 5 个元组，且 B 是 R 的主键，S(B,C) 有 10 个元组，则 R 与 S 按属性 B 进行自然连接后，结果元组数的取值范围是( )
A. [0, 5] B. [0, 10] C. [5, 10] D. [0, 50]
答案：B
关键：B 是 R 的主键 → 每个 B 值在 R 中唯一。因此，S 中每个元组最多与 R 中 1 个元组匹配。
最小：S 的 B 值与 R 的 B 值完全不重合 → 0 个结果元组。
最大：S 的 10 个元组的 B 值全部存在于 R 中 → 10 个结果元组。
5 某业务规则规定一个学生必须且只能属于一个班级；每个班级至少 10 人，至多 50 人。则学生实体参与该联系的基数应表示为( )
A. (10, 50) B. (0, 10) C. (0, 50) D. (1, 1)
答案：D
学生→班级：多对一。学生"必须且只能属于一个班级"，即每个学生恰好参与 1 个班级 → 学生侧基数 (min, max) = (1, 1)。
注意：(10,50) 是班级一侧的基数（每个班级至少 10 个学生、至多 50 个学生），不是学生侧。
6 在关系数据库中，实体与实体之间的联系通常通过表与表之间的( )来体现。
A. 公共属性 B. 顺序号 C. 页号 D. 聚簇索引名
答案：A
关系模型中，实体间的联系通过外键 → 主键的引用体现。外键引用主键，本质上是两张表拥有公共属性（同名同域），通过等值连接来关联。
7 倒排索引最主要的作用是( )
A. 加速文档内容搜索 B. 优化数据的存储结构，降低存储开销 C. 加快数据新增与修改的执行速度 D. 梳理数据关联，简化多表查询逻辑
答案：A
倒排索引（Inverted Index）的核心思想是"词 → 文档位置"的映射，通过关键词快速定位包含该词的文档。典型应用：搜索引擎（Elasticsearch）、数据库全文索引。存储开销反而增大（需要额外索引空间），写入性能也会降低（需维护索引）。

8 关系模式 R(U,F)，U={A,B,C}，F={A→B，B→C}。分解 ρ={R1({A,B}，F1)，R2({A,C}，F2)}，该分解( )
A. 有损连接但保持函数依赖 B. 既无损连接又保持函数依赖 C. 有损连接且不保持函数依赖 D. 无损连接但不保持函数依赖
答案：D
无损连接判定：R1 ∩ R2 = {A}，A 在 R1 中为超键（A→B）→ 无损 √
函数依赖保持：A→B 在 R1 中保留 √，B→C 无法从投影的 FDs 推导 → 不保持 ✗
结论：无损连接，但不保持函数依赖。
9 关系模式 R(U,F)，U={A,B,C,D,E}，F={B→A，D→A，A→E，AC→B}，则 R 的候选关键字为( )
A. CD B. ABD C. ACD D. ADE
答案：C
求闭包：(ACD)⁺ = {A,C,D} → A→E 得 E → AC→B 得 B → 全集 U。任意真子集闭包均 ≠ U。
验证：CD⁺ = {C,D,A,E} 缺 B；AC⁺ = {A,C,E,B} 缺 D；AD⁺ = {A,D,E} 缺 B,C。
∴ ACD 是极小候选键。
10 接上题，将 R 分解为 ρ={R1(ABCE)，R2(CD)}，该分解( )
A. 具有无损连接性，且保持函数依赖 B. 不具有无损连接性，但保持函数依赖 C. 具有无损连接性，但不保持函数依赖 D. 不具有无损连接性，也不保持函数依赖
答案：D
无损连接判定：R1 ∩ R2 = {C}，C 在 R1 和 R2 中均非超键 → 有损连接 ✗
函数依赖保持：D→A 中 A 不在 R2 中，该 FD 丢失 → 不保持 ✗
结论：有损连接，不保持函数依赖。
11 （2025上）关系模式 R(a,b,c,d)，函数依赖 a→cd，c→b，候选码是( )
A. a B. b C. c D. d
答案：A
a⁺ = {a,c,d} → c→b 得 b → 全集 {a,b,c,d} = U。a 为单属性，自然极小。
c⁺ = {c,b} ≠ U；b、d 更不可行。∴ 候选码为 a。

12 在封锁协议中，事务获取共享锁（S锁）后，对数据的操作权限是( )
A. 可读不可写 B. 可读可写 C. 不可读不可写 D. 不可读可写
答案：A
S 锁（共享锁 / 读锁）：持有锁的事务可读不可写。多个事务可同时持有同一数据的 S 锁（共享），但不能与 X 锁（排他锁）并存。
相容矩阵：S 与 S 相容 ✓，S 与 X 冲突 ✗。
