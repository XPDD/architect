▸ 核心要点
1进程管理 — 三态图 & 五态图

进程 = 程序运行的实例，是 资源分配和管理的基本单位。组成：PCB（进程控制块·唯一标志）+ 程序（描述要做什么）+ 数据（执行所需数据）。

3؀
三态图（系统自动）
  • 就绪：等待CPU调度
  • 运行：正在CPU上执行
  • 等待（阻塞）：等待某事件（如IO完成）
  • 转换：就绪→运行（调度）| 运行→就绪（时间片到）| 运行→等待（等待事件）| 等待→就绪（事件发生）
5؀
五态图（含人工操作）
  • 在三态基础上增加：静止就绪、静止阻塞
  • 需要人为操作才会进入对应状态
  • 活跃就绪 = 就绪，活跃阻塞 = 等待
1.1进程资源图 & 死锁判断

P=进程，R=资源，R框中圆圈数=资源数。R→P 表示已分配，P→R 表示还需请求。

  • 阻塞节点：所请求资源已全部被分完，无法获取 → 如 P2
  • 非阻塞节点：所请求资源还有剩余可分配 → 如 P1、P3
  • 死锁：当所有进程都是阻塞节点时，陷入死锁
1.2信号量 — PV 操作
P 操作（申请资源）
  • S = S - 1
  • 若 S >= 0：继续执行
  • 若 S < 0：阻塞，插入阻塞队列
vs
V 操作（释放资源）
  • S = S + 1
  • 若 S > 0：继续执行（无阻塞进程）
  • 若 S <= 0：唤醒一个阻塞进程 → 就绪队列
2存储管理 — 页式 · 段式 · 段页式
方式原理地址结构优缺点
页式存储 程序分固定大小页（4K），离散入内存块，用页表映射 逻辑地址 = 页号 + 页内偏移
物理地址 = 块号 × 块大小 + 页内偏移		 无外部碎片，但有内部碎片
段式存储 按逻辑整体分段，每段大小不同 地址 = （段号，段内偏移）
物理地址 = 段基地址 + 段内偏移		 优点：程序逻辑完整
缺点：内存碎片浪费大
段页式存储 先分段，后分页 段号 → 页号 → 页内偏移 优点：空间浪费小、共享容易、动态连接
缺点：复杂性↑、开销↑、速度↓

真题示例（段页式地址计算）

地址结构：段号(10位) + 页号(11位) + 页内偏移(12位) → 最多 2^10 = 1024 个段，每段最大 2^11 = 2048 个页，页大小 2^12 = 4KB。注意：是"最大允许"而不是"大小均为"。

3文件管理 — 索引文件 + 位示图
📁
索引文件结构
  • 13个索引节点：0-9 直接索引
  • 10号 一级间接：存放物理盘地址，容量×1024
  • 11号 二级间接：容量×1024×1024
  • 例：盘块4KB，地址4B → 直接=40KB，一级=4MB，二级=4GB
📊
位示图法
  • 每位标识一个物理空间，1=使用，0=空闲
  • 对比：
  • 空闲区表法 → 整合成空闲文件目录表
  • 空闲链表法 → 所有空闲空间链接成链表
  • 成组链接法 → 分组 + 组内链表的结合
4设备管理 — I/O 技术对比
技术工作原理适用场景效率
程序控制（查询）CPU主动查询外设是否完成，没完成就一直等待简单场景极低
通道技术（中断）CPU发出IO命令 → 通道执行→完成后中断通知CPU键盘鼠标等实时性高设备中等
DMA（直接主存存取）数据在主存与IO设备间成块直接传送，CPU只在开始/结束时介入硬盘等高速设备高
缓冲技术通过硬件寄存器或软件管理缓冲，提高外设利用率通用加速中高
Spooling磁盘缓冲区将独占设备虚拟化为多台共享虚拟设备打印机等独占设备提高并发
◆ 费曼

操作系统到底在考什么？ 四个字：进程存储。进程管理 = 程序怎么跑（三态五态、PV操作、死锁判断）；存储管理 = 内存怎么用（页式像切豆腐块大小固定、段式像撕面包大小不一、段页式先撕再切）；文件管理 = 磁盘文件怎么存（索引节点像目录、位示图像停车场车位图）；设备管理 = CPU怎么跟外设打交道（死等/中断/DMA三种档次）。PV操作口诀：P是Probieren（试）申请资源减减减，V是Verhogen（增）释放资源加加加。
