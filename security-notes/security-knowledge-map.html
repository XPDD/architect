横切 / 支撑模块

PK

PKI / CA 体系

非对称密钥的可信第三方：CA 签发数字证书，解决「公钥是谁的」信任问题。公钥加密保机密，私钥加密做签名。

访问控制

主体 + 客体 + 控制策略三要素：规定「谁能对什么资源做什么」，是可控性的落地手段，配合身份认证使用。

◆ 核心关系（一句话记住）

信息安全先定目标——五要素（机密/完整/可用/可控/可审），再用技术逐层实现：
加密与认证解决「保密与验证」→ 抗攻击技术抵御「攻击手段」→ 网络安全布好「网络防线」→ 保证与评估度量「等级与风险」。
贯穿全程的是防范体系五层（物理/系统/网络/应用/管理），配套 PKI/CA（信任）、访问控制（授权）、安全管理（闭环）三大支撑。
