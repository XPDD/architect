▸ 核心要点
1基本概念

流水线是程序执行时多条指令重叠操作的一种准并行技术。各部件同时为不同指令的不同部分工作，提高部件利用率和平均执行速度。一条指令通常分解为取指、分析、执行等子过程。

流水线周期 = 各子过程执行时间的最大值（最慢的那段）。

2执行时间公式

n 条指令、k 段子过程，各段耗时 t₁…t_k：

T = (t₁+t₂+…+t_k) + (n−1) × max(tᵢ)

  • 第一项：第 1 条指令从头到尾「填满」整条流水线的时间。
  • 第二项：后面 n−1 条，每条只需一个「流水线周期」。
3吞吐率 TP

TP = 完成的任务数 n / 总时间 T；最大吞吐率 TPmax = 1 / 流水线周期。

4加速比 S

S = 不使用流水线的时间 / 使用流水线的时间 = n·(t₁+…+t_k) / [(t₁+…+t_k) + (n−1)·max(tᵢ)]

5算例（真题）

取指 5△t、分析 2△t、执行 3△t，执行 500 条指令：

  • 流水线周期 = max(5,2,3) = 5△t
  • T = (5+2+3) + (500−1)×5 = 10 + 2495 = 2505△t
◆ 费曼

流水线像「食堂打饭」：取指、分析、执行是三个窗口。第一个人三个窗口都跑一遍（Σtᵢ），之后每隔一个「最慢窗口的时间」（周期=最慢那一段）就出一个菜。所以总时间 = 第一个人的全程 + (总人数−1)×最慢窗口时长。人越多，加速比越接近「段数」。

▸ 总结

流水线周期=最慢段耗时；T=(t₁+…+t_k)+(n−1)×周期；TP=n/T，最大吞吐率=1/周期；加速比=串行时间/流水时间。500 条(5,2,3)△t → 2505△t。
