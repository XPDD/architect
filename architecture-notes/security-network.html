▸ 核心要点
▶ 去做题 · 网络安全协议练习（3 题） 点选判分 · 带解析
1防火墙
网络级防火墙
  • 层次低、效率高
  • 包过滤 + 状态监测
  • 只查数据包外在属性（地址/状态）
  • 对应用和用户透明，防不住伪装包
VS
应用级防火墙
  • 层次高、效率低
  • 拆包检查内部数据
  • 安全强度高
  • 消耗大量时间
2IDS / IPS / 杀毒 / 蜜罐
  • IDS 入侵检测：防火墙后第二道屏障，监听设备（不跨接链路），匹配知识库检测入侵，补防火墙对内网攻击无能为力的短板
  • IPS 入侵防御：提前发现并直接阻断（IDS 是事后检测，IPS 是提前防御）
  • 杀毒软件：检测解决计算机病毒（防火墙处理网络非法攻击，分工不同）
  • 蜜罐：伪造蜜罐网络引诱黑客，了解攻击手段并优化系统
3网络安全协议
协议用途
SSL安全套接字，加强 Web 传输，+HTTP 成 HTTPS，端口 443
SSH安全外壳，加强 Telnet/FTP
SET安全电子交易，B2C 电子商务支付，保机密/真实/完整/不可否认
Kerberos网络身份认证，基于信任第三方（KDC），不依赖 OS/IP
PGP安全邮件：RSA 认证 + IDEA 加密 + MD5 完整性
S/MIME对 MIME 的安全扩展，提供安全电子邮件
3.1第三方认证两种体制（易混淆考点）

第三方认证指由可信第三方为用户提供身份认证，主要有两种体制：

  • Kerberos：基于对称密钥，信任第三方服务器 KDC（密钥分发中心 Key Distribution Center），不依赖主机 OS 和 IP 地址。
  • PKI（公钥基础设施）：基于非对称密钥，由 CA（认证中心 Certificate Authority）签发数字证书。

记忆口诀：Kerberos ↔ KDC（对称）、PKI ↔ CA（非对称），两者别搞反。保存数字证书的服务器叫 CA（属于 PKI），不是 KDC；Kerberos 的中文是「网络身份认证协议」，不是「公钥基础设施」。

◆ 费曼

网络防线说人话：防火墙＝门卫，只查进出大门的人（网络级只查身份牌，应用级还要开包检查）；IDS＝门里的监控摄像头，只记录不拦人；IPS＝带自动报警的电动门，一发现异常直接锁死；杀毒＝医生，专治病毒；蜜罐＝故意放个假金库引贼上钩。协议就是给不同场景配的"加密对话方式"——上网用 SSL，远程登录用 SSH，网购支付用 SET，进公司打卡验身份用 Kerberos，发加密邮件用 PGP。

4网络攻击分类（被动 vs 主动）
被动攻击（3 种）
  • 窃听（网络监听）：窃取信息资源和敏感信息
  • 业务流分析：长期监听，统计分析通信频度/流向/总量
  • 非法登录（部分资料归入此类）
VS
主动攻击（5 种）
  • 假冒身份：非法用户冒充合法用户（黑客最常用）
  • 抵赖：否认发布过的消息、伪造来信
  • 旁路控制：利用安全缺陷获取非授权权利
  • 重放攻击：截获合法通信数据重新发送
  • 拒绝服务 DoS：阻止合法访问
5OSI 各层对应的安全协议
OSI 层安全协议 / 技术
应用层PGP、HTTPS
会话层SSL（横跨应用/表示/会话层）
传输层TLS、SET
网络层防火墙、IPSec
数据链路层链路加密、PPTP、L2TP
物理层隔离、屏蔽

▸ 总结

防火墙分网络级（低层高效）与应用级（高层低效）；IDS 监听事后检测，IPS 提前阻断；网络攻击分被动（窃听/业务流分析/非法登录）与主动（假冒/抵赖/旁路/重放/DoS）；安全协议按 OSI 层分布——SSL 会话层、TLS/SET 传输层、IPSec 网络层、PPTP/L2TP 链路层；SSL 保 Web（443）、SSH 保远程、Kerberos 保认证、PGP/S-MIME 保邮件。
