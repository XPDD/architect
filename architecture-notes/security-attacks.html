▸ 核心要点
1DoS / DDoS 拒绝服务攻击
  • DoS：内/外部用户通过长时间占用内存、CPU 或网络连接，使其他用户得不到资源
  • DDoS：控制多台"肉鸡"同时攻击同一目标，克服了传统 DoS 的资源限制与隐蔽性两大缺点
  • 防御：特征识别数据包、防火墙监视端口、统计通信数据量、修正漏洞
2ARP 欺骗

主机只要收到响应分组就刷新 IP-MAC 映射（不管是否请求过），攻击者 C 伪造正确 IP + 自己 MAC 的响应，使 A 把发往 B 的数据发到 C。防范：固化 ARP 表、ARP 服务器、双向绑定、ARP 防护软件。

3DNS 欺骗

冒充 DNS 服务器，把域名解析到攻击者 IP，用户只能看到攻击者主页。检测：被动监听检测、虚假报文探测、交叉检查查询。

4IP 欺骗

使被冒充主机瘫痪 → 连接目标机猜 ISN → 伪装源地址发 SYN → 等 SYN+ACK → 冒充发 ACK（预测 ISN+1）→ 建立连接。防范：删除 /etc/hosts.equiv、$HOME/.rhosts，防火墙过滤源地址是内部 IP 的外部报文。

5端口扫描
  • 全 TCP 连接：完整三次握手
  • 半打开式（SYN 扫描）：收 SYN+ACK 即回 RST，不完成握手
  • FIN 扫描：活动端口丢弃报文不回，死端口回 RST（最安全，秘密扫描）
  • 第三方扫描（代理扫描）：用"肉鸡"代扫
6强化 TCP/IP 堆栈
  • SYN Flooding：利用 TCP 缺陷，三次握手只做两次，大量半连接占满队列（可改注册表防御）
  • ICMP 攻击：如 Ping of Death（数据包超 64KB 使堆栈崩溃）
  • SNMP 攻击：控制设备、重定向通信流
  • 系统漏洞扫描：基于网络扫描 / 基于主机扫描
◆ 费曼

欺骗攻击说人话：ARP 欺骗＝小区里有人冒领你的快递（冒充收件人地址）；DNS 欺骗＝问路时假交警给你指到黑店；IP 欺骗＝有人顶替你的工牌混进公司。SYN Flooding＝一直跟客服"喂"一声就挂断，占满电话线让真客户打不进来。防御思路都是核实身份 + 锁定映射 + 过滤异常。

▸ 总结

常见抗攻击技术：DoS/DDoS（耗尽资源）、ARP/DNS/IP 欺骗（伪造身份映射）、端口扫描（全TCP/SYN/FIN/第三方）、SYN Flooding（半连接耗尽队列）；防御靠特征识别、固化映射、过滤异常与修正漏洞。
