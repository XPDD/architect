▸ 核心要点
1嵌入式系统介绍

嵌入式系统是为特定应用专门构建的计算机系统。发展五阶段：

  • SCM 单片微型计算机（计算器）、MCU 微控制器（汽车电子/医疗器械）、SoC 片上系统（麒麟芯片）、互联网嵌入式（智能家居）、智能化云技术（智能穿戴/汽车）。
  • 组成：嵌入式微处理器(MCU)、存储器(RAM/ROM)、内(外)总线、定时/计数器、看门狗电路、I/O 接口、外部设备。
  • 微处理器分类：MPU、MCU、DSP、GPU、SoC。
2嵌入式操作系统 + 实时系统
  • 两种典型架构：层次化模式（划分为多层）与递归模式（自相似子系统）。
  • EOS 特点：可裁剪、可移植、强实时、强紧凑、高质量代码、强定制、标准接口、强稳定、弱交互、强确定、操作简洁、硬件适应、可固化。
  • 4 种结构：整体结构、层次结构、客户/服务器结构、面向对象结构。
  • 实时系统：要求确定性和可预测性。RTOS 分硬实时（规定时间内必须完成，设计时保证）和软实时（按优先级尽可能快完成）。特征：高精度计时、多级中断机制、实时调度机制。
3软件可靠性（定量描述）
  • 软件可靠性：软件产品在规定的条件下和规定的时间区间完成规定功能的能力。
  • 软件 vs 硬件可靠性：软件复杂性高（失效多为软件失效）；硬件失效主要是物理退化、软件不存在物理退化；软件唯一（复制不改变本身）；软件更新快。
  • 可靠度＝规定条件/时间不发生失效的概率＝1-失效概率；MTTF平均无故障时间、MTTR平均修复时间、MTBF平均故障间隔时间，MTBF=MTTF+MTTR。
4可靠性设计（容错 + 检错）

可靠性设计：在软件设计阶段采取措施进行可靠性控制（最有效、最经济、最重要）。设计原则：不与其他设计原则冲突、以可靠为目标、确定目标不无限扩大（排在功能度/用户需求/开发费用之后）。

  • 容错设计：系统发生硬件故障/软件错误时仍能保持正常工作。三种技术：冗余设计（硬件/软件冗余替代故障资源）、恢复块设计（回滚恢复/前向恢复）、N 版本程序设计（N 个独立设计的程序同时执行、投票表决）。
  • 检错设计：故障后及时发现并报警，代价低于容错但需人工干预。四要素：检测对象、检测延时、实现方式（判断返回结果）、处理方式（停运行-报警）。
  • 系统配置技术：双机热备份（心跳检测、主备切换）、服务器集群（负载转嫁、功能整合、故障过渡）。
  • 负载均衡：基于特定软件(Nginx/HAProxy)、DNS、NAT、反向代理、混合型。
5鸿蒙操作系统架构

鸿蒙（HarmonyOS）采用分层层次化设计，从下向上四层：内核层 → 系统服务层 → 框架层 → 应用层，按「系统→子系统→功能/模块」逐级展开，支持按需裁剪。

  • 内核层：内核子系统（多内核设计、内核抽象层屏蔽差异）+ 驱动子系统。
  • 系统服务层：核心能力集合，含系统基本能力、基础软件服务、增强软件服务、硬件服务 4 部分。
  • 框架层：提供 Java/C/C++/JS 多语言用户程序框架和 Ability 框架、多语言框架 API。
  • 应用层：系统应用+第三方应用，由 FA（有 UI 交互能力）或 PA（无 UI、后台运行）组成。

4 个技术特性：分布式架构首次用于终端 OS、确定时延引擎+高性能 IPC、基于微内核的可信安全、统一 IDE 一次开发多端部署。分布式四优势：分布式软总线、分布式设备虚拟化、分布式数据管理、分布式任务调度。

6真题 — 数据流软件可靠性计算

串并联可靠性：串联 R = R1×R2×…×Rn（一个坏全坏）；并联 R = 1-(1-R1)(1-R2)…(1-Rn)（全坏才坏）。

  • 案例：4 个模块可靠度各 0.99，全串联可靠度 = 0.99⁴ ≈ 0.96，明显下降且任一模块失效全系统失效。
  • 动态冗余（主动冗余）：故障检测/定位/恢复，多重模块待机储备，备用模块待机可工作（热备份/双重系统）或不工作（冷备份/双工系统）。
  • N 版本程序设计：静态故障屏蔽，N 个独立设计的程序同时执行、多数表决。
  • M2 采用 3 份动态冗余后可靠度 = 1-(1-0.99)³ = 0.999999；整个系统 = 0.99×0.999999×0.999999×0.99 ≈ 0.98。
  • 检错技术：代价低于容错但不能自动解决故障、需人工干预；实现方式＝判断返回结果/计算运行时间/置状态标志位；处理方式＝查处故障-停止运行-报警。
◆ 费曼

嵌入式可靠性说人话：可靠性就是「串起来会变脆，并起来才结实」——串联一个坏了全完蛋（可靠度相乘，越乘越小），并联只有全坏才坏（可靠度用 1-(1-R)ⁿ 算）。要扛故障就用容错三件套：多备几份（冗余）、坏了重跑（恢复块）、多版本投票（N 版本）。鸿蒙记住「内核→系统服务→框架→应用」四层 + 分布式四大件（软总线/设备虚拟化/数据管理/任务调度）。

▸ 总结

嵌入式发展五阶段SCM→MCU→SoC→互联网→智能云；RTOS 分硬实时/软实时，强调确定性和可预测性；可靠性指标MTBF=MTTF+MTTR；串联 R=∏Rᵢ、并联 R=1-∏(1-Rᵢ)；容错三技术冗余/恢复块/N 版本；鸿蒙内核层→系统服务层→框架层→应用层四层 + 分布式四优势。本题选做，掌握可靠性计算即可。
