▸ 核心要点
1SQL 五大功能
分类作用语句
DDL定义数据库对象CREATE / ALTER / DROP
DML数据增删改INSERT / UPDATE / DELETE
DQL查询记录SELECT … FROM … WHERE … GROUP BY … HAVING … ORDER BY … LIMIT
TCL事务控制COMMIT / ROLLBACK / SAVEPOINT
DCL权限安全GRANT / REVOKE（用户/角色）

DQL 要点：order by 默认升序 ASC（降序 DESC）、limit 分页（下标从 0 开始）、group by 分组（配 having 加条件）、like（% 多字符、_ 单字符）。

2应用程序访问数据库的四种接口
接口特点典型
库函数级别最底层、效率低、依赖特定数据库OCI
嵌入 SQLSQL 写进源码，需预编译器，麻烦且性能不高—
通用数据接口标准统一接口直接操作数据ODBC（后发展 DAO/RDO/ADO、.NET 的 ADO、Java 的 JDBC）
ORM对象与表映射，开发效率最高Hibernate / MyBatis / JPA
3NoSQL（Not Only SQL）
分类说明代表产品
列式存储按行列存储，应对海量分布式数据HBase
键值对存储key-value，简单易部署Redis
文档型键值对升级版，允许嵌套，处理复杂数据高效MongoDB
图数据库图模型，适合社交网络/交通网络Neo4J

特征：易拓展、大数据量、高性能、灵活数据模型、高可用（不保证 ACID）。框架分层（自下而上）：数据持久层 → 数据分布层 → 数据逻辑模型层 → 接口层。

◆ 费曼

SQL 五类像"五顶帽子"：DDL 改结构、DML 改数据、DQL 查数据、TCL 管事务、DCL 管权限。访问接口从"手写底层调用（OCI）"到"写 SQL 字符串（ODBC/JDBC）"再到"直接操作对象（ORM）"，越往上越省事。NoSQL就是不保证 ACID 的"轻量快"数据库：Redis 存键值、MongoDB 存文档、HBase 存列、Neo4J 存图。

▸ 总结

SQL 五大功能：DDL 定义、DML 增删改、DQL 查询、TCL 事务、DCL 权限。访问接口：库函数(OCI)→嵌入 SQL→通用接口(ODBC/JDBC)→ORM。NoSQL 四分类：列式 HBase、键值 Redis、文档 MongoDB、图 Neo4J。
