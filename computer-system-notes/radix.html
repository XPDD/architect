▸ 核心要点
1二进制 → 十进制
  • 无符号整数：从右往左，每位乘以 2 的 n 次幂之和（n 从 0 开始）。
  • 带符号整数：除去最高位符号位（1 负 0 正），其余同无符号。
  • 小数：小数点后第 1 位乘 2⁻¹，第 2 位乘 2⁻²，以此类推。
2十进制 → 二进制
  • 整数：除 2 取余，商不为 0 继续除，余数按从下到上记录。
  • 小数：乘 2 取整，直到小数部分为 0 或达到精度，取整结果按从上到下记录。
3算例
  • 1100.101₂ = 8+4+0.5+0.125 = 12.625₁₀
  • 11.75₁₀：11=1011，0.75=0.11 → 1011.11₂

补充：二→八进制每 3 位一组，二→十六进制每 4 位一组（不足左侧补 0）。

◆ 费曼

二进制换十进制就是「按位权加权求和」：整数从个位往左，每位是 2⁰、2¹、2²……；小数点往右是 2⁻¹、2⁻²……。反过来十进制转二进制：整数「除 2 取余、倒着写」，小数「乘 2 取整、顺着写」。记住 1100.101 = 12.625、11.75 = 1011.11 两个例子就能举一反三。

▸ 总结

二→十按位权求和（整数 2ⁿ，小数 2⁻ⁿ）；十→二整数「除2取余倒序」、小数「乘2取整正序」。例：1100.101₂=12.625、11.75₁₀=1011.11₂。
